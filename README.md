# Procesamiento y Clasificación de Datos

- [Tarea #1](https://github.com/GemaGuerraV/Procesamiento-Clasificaci-nDatos/blob/main/Tarea%231_PCD.md)

Se realiza un análisis estadístico sobre 2 obras de Edgar Allan Poe. Se analizan estadísticas descriptivas básicas, frecuencias, distribuciones de palabras, n-gramas y uso de signos de puntuación.

- [Tarea #2](https://github.com/GemaGuerraV/Procesamiento-Clasificaci-nDatos/blob/main/Tarea2_PCD.ipynb)

Se elige un método de vectorización adecuado para el conjunto de datos de Yelp, se aplica y estudian las propiedades de los vectores obtenidos. Se realiza un análisis de sentimientos.

- [Tarea #3](https://github.com/GemaGuerraV/Procesamiento-Clasificaci-nDatos/blob/main/Tarea3_PCD.ipynb)

Se utiliza Random Forest para clasificar texto, pero se usa Diseño de Experimentos (DOE) como herramienta para auditar, comparar y demostrar cuál es la calibración óptima de ese modelo. 

- [Tarea #4](https://github.com/GemaGuerraV/Procesamiento-Clasificaci-nDatos/blob/main/Tarea%234_PCD.md)

Se encuentran centros de objetos circulares de una imagen y se analiza por medio de histogramas.
